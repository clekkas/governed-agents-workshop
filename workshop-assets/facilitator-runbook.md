# Facilitator Runbook

## Before the workshop

1. Confirm that only synthetic data will be used.
2. Confirm Fabric, Foundry, Azure, and identity prerequisites.
3. Confirm whether the BYO Registry sample repo is available.
4. Print or share the module sequence and decision log.

## During the workshop

Capture decisions in these categories:

1. Architecture
2. Security
3. Governance
4. Data/RAG
5. Tooling
6. HITL
7. Observability
8. Evaluation
9. Roadmap

## Closing script

The desired output is a secure agent blueprint, not a clinical automation claim. The agent drafts, retrieves, explains, cites, and routes. Humans approve operational care-management actions.
