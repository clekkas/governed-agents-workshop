# Module 09: Evaluation and Release Gates

## Objective

Define release gates for safety, groundedness, PHI minimization, tool authorization, HITL routing, quality, and observability.

## Evaluation types

1. Golden cases.
2. Adversarial cases.
3. Tool-denial cases.
4. PHI-minimization cases.
5. Groundedness cases.
6. HITL routing cases.
7. Regression cases.

## Output

Evaluation rubric, calibration set, and release checklist.
