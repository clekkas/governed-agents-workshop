# Module 08: End-to-End Readmissions Flow

## Objective

Walk through the full governed workflow.

## Flow

1. Care manager selects a synthetic case.
2. Agent starts invocation and correlation ID.
3. Agent retrieves approved protocol evidence.
4. Agent requests scoped patient and utilization context through MCP.
5. Policy layer validates output.
6. Agent drafts transition gaps, proposed owners, due times, and task/outreach text.
7. HITL task is created.
8. Reviewer approves, rejects, or requests rework.
9. Telemetry and audit events are correlated.

## Output

Trace map and pilot-readiness checklist.
