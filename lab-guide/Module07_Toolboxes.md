# Module 07: Toolboxes

## Objective

Package reusable capabilities into scoped toolboxes.

| Toolbox | Example tools |
| --- | --- |
| Clinical context | `patient.get`, `notes.get` |
| Protocol | `protocol.search`, `protocol.get` |
| Utilization | `utilization.history`, `risk.signals` |
| Care coordination | `task.create`, `appointment.options` |
| Operations | `audit.write`, `telemetry.emit` |

## Output

Toolbox inventory with owners, scopes, schemas, and release gates.
