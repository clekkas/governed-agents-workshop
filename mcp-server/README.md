# MCP Server

This folder defines the governed tool boundary for the workshop. Implementation will be added after the target runtime and BYO Registry sample are incorporated.

Every tool must enforce:

1. Typed input and output schemas.
2. Caller authorization.
3. Patient-context validation.
4. PHI-minimizing defaults.
5. Deterministic denial behavior.
6. Audit logging.
7. Correlation ID propagation.
